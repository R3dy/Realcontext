# INVARIANTS — realcontext

> **Status:** Initial invariant set, mapped 2026-08-30 at commit `06a8165` (v0.1.0) · project_type: `library`
> Derived from: as-built code, Phase 4 decisions (`DECISIONS.md`), and the `library` type's
> success model. Each invariant names where it is enforced in code and how it is verified.
> **Changes to any invariant require an explicit superseding decision** — see DECISIONS.md.

| ID | Invariant | Why it exists | Enforced at | Verified by |
|----|-----------|---------------|-------------|-------------|
| **INV-1** | Session-usage reads against OpenCode's SQLite DB are **strictly read-only**: `DatabaseSync(path, { readOnly: true })`, a single prepared `SELECT`, connection closed in `finally`. Never write, migrate, lock, or otherwise touch OpenCode's data | The DB belongs to the host agent; corruption there breaks every user session | `src/usage.ts:71-98` (`readOnly: true`, `finally { db.close() }`) | Code review; D-1 rationale; no test touches a real DB |
| **INV-2** | The plugin must **never break OpenCode startup or the chat pipeline**: every hook body is wrapped in defensive try/catch, all side-effect writes are best-effort, and any failure degrades to estimated output | The plugin loads into the host's startup path; a throw corrupts the user's session | `src/plugin.ts` — all three surfaces (`experimental.chat.system.transform` 70-78, `event` 80-100, `context_report` tool 102-119); comment "never break the host" | D-7; manual live verification (v0.1.0 installed and running on this box) |
| **INV-3** | Output must **render with zero capture and zero usage**: `buildBreakdown` and all renderers tolerate `capture: null` and `usage: null` without throwing (estimated mode shows system `tokens: 0` with a "no capture yet" note) | A fresh session, a headless box, or a DB hiccup must still produce a usable report | `src/report.ts:38-53` (null-capture system item), null-safe renderers 201-252 | test "builds estimated-only breakdown without usage" (9-test suite). ⚠ Structural completeness gap when `usage` is null → DRIFT-3 (open) |
| **INV-4** | Tests are **hermetic**: the suite must pass with no live OpenCode session, no OpenCode SQLite DB, and no network — fixture trees in `mkdtemp` tmpdirs with fully injectable paths | CI/any-box testability; `readUsage` is the only live-DB-coupled function and tests never call it | `test/realcontext.test.ts` (`beforeAll` fixture build, `afterAll` cleanup); injectable `scanAll`/`scanRules`/`scanSkills` signatures in `src/scan.ts` | 9/9 vitest green at `06a8165` on this box; no fixtures reference `$HOME` real data |
| **INV-5** | **Honest measured-vs-estimated labeling**: `measured: true` only for real bytes (captured system prompt, fingerprint-matched sources, provider usage numbers); everything else is a chars/4 estimate and is labeled as such in every rendered row, with the `est = chars/4` legend | The product's core promise is truthful visibility; a silent guess presented as fact is a correctness bug, not a nit | `src/tokens.ts:17` (`ItemDetail.measured`), `src/report.ts` renderers (per-row `measured`/`estimate` columns, legend at 246) | tests "fingerprint-attributes…" and "builds measured breakdown with usage"; ⚠ known violations tracked as DRIFT-1/DRIFT-2 (Issue #1) |
| **INV-6** | The estimator stays **dependency-free and deterministic**: pure `chars/4` (`CHARS_PER_TOKEN = 4`, `Math.ceil`), no tokenizer model download, no wasm, pure functions | Adoption (library success axis): nothing to download, nothing platform-dependent, results reproducible across runs | `src/tokens.ts:49-55` (pure function, no imports) | test "estimates chars/4 and handles empties"; D-2 |
| **INV-7** | realcontext is an **observer**: it writes only inside its own namespace (`~/.cache/realcontext/*` for captures/status/usage-cache; reads `~/.config/opencode/realcontext.json` and config files read-only). It never mutates OpenCode's DB, config, sessions, or any project file | A visibility tool that mutates what it observes is untrustworthy and dangerous | `src/capture.ts` (`cacheDir()` namespace, atomic writes), `src/plugin.ts:38-67` (`writeStatus` writes), `src/usage.ts` (read-only DB) | Code review; INV-1 overlap; D-9 |
| **INV-8** | The CLI works **standalone with no OpenCode runtime or plugin installed**: no SDK import at CLI runtime; capture/usage absence flows through as nulls | Headless use (scripts, status bars) is a first-class surface; requiring a live host would break `status.txt` consumers and CI | `src/cli.ts:1-59` (imports only local modules; `measuredContext()` returns null gracefully), `package.json` bin | test "builds estimated-only breakdown without usage" exercises the null path; D-11 |
| **INV-9** | Disk scanning **survives arbitrary broken/missing trees**: all file reads go through safe readers (`readTextSafe`, `readJsonSafe`, `existsFile`); missing/unreadable dirs yield empty arrays, never throws | Users have wildly varied filesystems; a malformed `opencode.jsonc` or missing dir must not kill the report | `src/scan.ts:37-62` (safe readers, used throughout), `skillRoots`/`scanMcps`/`scanPlugins` try/catch around `readdirSync` | test "survives missing dirs" |
| **INV-10** | Captures are **atomic and bounded**: writes are tmp-file + rename (tmp cleaned on failure), cache pruned to the latest 5 capture files | A half-written capture must never be parsed as truth; unbounded cache growth on long-lived boxes | `src/capture.ts:35-47` (`atomicWrite`), `src/capture.ts:58-69` (`pruneCaptures(keep = 5)`) | Code review; D-9 |
